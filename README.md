Notebooks for the course *Scripting Languages* (H0P66A / G0W95B), Tim Van de Cruys.
Slides, announcements and everything else are on Toledo.

## How to use these notebooks

- **Google Colab:** click the Colab link next to a notebook. The notebook opens read-only,
  so first choose **File > Save a copy in Drive**; otherwise your work is lost when you close the tab.
- **Jupyter on your own computer:** open the notebook on GitHub and use the download button
  (top right of the file view), then open the `.ipynb` file in Jupyter.

Solutions are added to the `solutions` folder after each practical session.
